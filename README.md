# Coastal Safety Solutions — Award Site V2

Brand new responsive Next.js 16 + GSAP website concept built from scratch.

## Run

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Included

- Fully generated cinematic website imagery
- GSAP hero reveal
- ScrollTrigger parallax
- Center-view image scaling and grayscale-to-color transitions
- Z-axis background rotation
- Particle-burst star navigation
- Abstract geometric navigation shapes
- Scroll-revealed manifesto
- Scroll-constructed wireframe building
- Desktop cursor tilt feedback
- Neon interaction lines
- Infinite-style scrolling ticker
- Sticky training index
- Responsive layouts for desktop, tablet and mobile
- `prefers-reduced-motion` accessibility fallback
